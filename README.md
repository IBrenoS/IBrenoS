### About Me

I'm a Software Engineering student at **Universidade Jorge Amado (UNIJORGE)**, based in Salvador, Brazil.

I build full-stack applications and digital products, working across user interfaces, backend services, databases, and infrastructure. I enjoy exploring how software architecture, design, and modern development tools come together to create useful, well-structured applications.

AI is also part of my development workflow, supporting problem-solving, code analysis, experimentation, and the exploration of intelligent features in software products.

- 🤖 Working with AI-assisted development and exploring AI-powered solutions.
- 🧩 Interested in software architecture, system design, and infrastructure.
